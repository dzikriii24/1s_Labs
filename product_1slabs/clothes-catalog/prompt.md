Jadi, jangan dibuat seperti template toko online pada umumnya. Kita ingin website yang ketika dibuka terasa seperti brand fashion independen yang punya karakter, eksklusivitas, dan identitas visual kuat.

Dari poster yang kamu lampirkan, ada beberapa karakter visual yang menarik untuk dijadikan inspirasi:

- Bold typography: tipografi besar, tegas, dan berani.
- High contrast: dominasi hitam dan putih dengan aksen merah.
- Halftone texture: tekstur fotografi seperti cetakan editorial.
- Streetwear identity: kesan raw, rebellious, artistik, dan tidak terlalu formal.
- Editorial composition: penggunaan foto sebagai elemen utama, bukan sekadar pelengkap card produk.

Namun, saya menyarankan agar karakter tersebut digunakan terutama untuk campaign banner, hero section, dan materi promosi. Sementara katalog dan halaman transaksi harus tetap bersih, minimalis, dan mudah digunakan.

Untuk mempertajam eksklusivitas, saya akan mengarahkan desainnya ke perpaduan editorial streetwear + minimal luxury e-commerce.

## Prompt pembuatan design.md

# TASK: Create a Comprehensive `design.md` for an Exclusive Streetwear E-Commerce Platform

## 1. Project Overview

I want to develop a premium fashion e-commerce website focused on clothing products, especially independent streetwear and exclusive apparel collections.

The website must communicate:

- Exclusivity and limited product availability.
- Strong brand identity and visual storytelling.
- Premium shopping experience.
- Minimalist but distinctive visual design.
- A seamless and professional e-commerce experience.

The main design direction is:

**Premium Independent Streetwear meets Editorial Fashion E-Commerce.**

This website must NOT look like a generic e-commerce template, a typical marketplace, or an AI-generated website.

The final design should feel like a real fashion brand with a strong creative direction, similar in quality and presentation to established independent fashion labels.

## 3. Overall Design Principles

### A. Visual Identity

The website should have a recognizable visual identity.

Preferred direction:

- Minimalist.
- Editorial.
- Contemporary streetwear.
- Premium.
- Bold typography.
- Strong photographic composition.
- High contrast.
- Clean layouts with intentional whitespace.

Suggested color direction:

| Color               | Usage                                              |
| ------------------- | -------------------------------------------------- |
| Black (#0A0A0A)     | Primary typography, navigation, important elements |
| White (#FFFFFF)     | Main background                                    |
| Off-white (#F5F4F0) | Secondary backgrounds                              |
| Charcoal (#292929)  | Secondary text                                     |
| Red (#E52323)       | Selective campaign accent                          |

Red must be used sparingly. It should communicate campaign identity, not become the dominant interface color.

### B. Typography

Typography is one of the most important elements of this project.

Use a combination of:

- Bold grotesk sans-serif for headlines.
- Neutral sans-serif for body text.
- Condensed typography for selected campaign elements.
- Small uppercase typography for product metadata and editorial labels.

Suggested font families:

- Archivo
- Helvetica Neue
- Inter
- Space Grotesk
- Oswald

Choose a maximum of two primary font families.

Avoid excessive font combinations.

### C. Photography and Images

Product photography must be the primary visual element.

Requirements:

- High-quality product images.
- Consistent image ratios.
- Neutral or editorial backgrounds.
- Clear product details.
- Front and back product photography.
- Lifestyle photography for campaign sections.
- Proper image cropping and positioning.

Use real product photography whenever available.

Do not use random stock images as substitutes for actual products.

### D. Anti-AI-Slop Design Rules

This is a strict requirement.

Avoid:

- Excessive rounded cards.
- Unnecessary gradients.
- Glassmorphism.
- Excessive floating elements.
- Random decorative shapes.
- Excessive shadows.
- Too many badges.
- Emoji as icons.
- Oversized dashboard-style components.
- Generic AI-generated landing page layouts.
- Unnecessary animations.
- Repeated card patterns across every section.
- Excessive use of pill-shaped buttons.
- Decorative elements that do not serve a purpose.

Icon guidelines:

- Use Lucide Icons or another consistent professional icon library.
- Use consistent stroke width and sizing.
- Never use emojis as interface icons.
- Avoid mixing different icon styles.
- Use icons only when they improve usability.

Badges should only be used when genuinely necessary, such as SOLD OUT or LIMITED STOCK.

The design must prioritize typography, photography, spacing, hierarchy, and composition.

### E. Checkout and Payment Gateway

The payment gateway must use **Xendit**.

The checkout experience should be clean, secure, and professional.

Required checkout information:

1. Customer information.
2. Email address.
3. Phone number.
4. Shipping address.
5. Shipping method.
6. Order summary.
7. Discount or voucher, if supported.
8. Total payment.

Payment methods should be retrieved from the supported Xendit integration.

Possible methods include:

- Virtual Account.
- QRIS.
- E-Wallet.
- Retail outlets.
- Other payment methods enabled in the merchant account.

Payment flow:

1. Customer reviews the order.
2. Customer selects a payment method.
3. Backend creates the payment request through Xendit.
4. Customer completes payment using the provided payment instructions.
5. Backend receives and verifies Xendit webhook notifications.
6. Order payment status is updated.
7. Customer receives order confirmation.

Important:

- Never trust payment status from frontend alone.
- Validate Xendit webhook signatures.
- Implement idempotency to prevent duplicate payment processing.
- Do not store sensitive payment credentials.
- Keep transaction records.
- Provide clear payment pending, success, expired, and failed states.

The payment integration must use Xendit's official API/SDK and current documentation.

## Saran tambahan sebelum development

Ada beberapa hal yang menurut saya penting agar website ini benar-benar terasa seperti brand eksklusif:

1. Limited drop system: produk bisa memiliki jadwal release dan kuota stok tertentu.
2. Product variants: setiap kombinasi size dan color mempunyai stok masing-masing.
3. Recently viewed: simpan produk yang terakhir dilihat.
4. Community submissions: pelanggan bisa mengirimkan foto untuk ditampilkan di halaman community.
5. Campaign CMS: admin bisa mengganti hero banner, campaign, typography content, dan featured collection tanpa mengubah kode.
6. Editorial product photography: jangan menyamakan semua foto produk dengan template gambar putih polos. Kombinasikan studio photography dan lifestyle photography.

Satu hal yang paling saya tekankan: jangan sampai kesan eksklusif hanya berasal dari warna hitam, font tebal, dan tulisan LIMITED EDITION. Eksklusivitas harus terasa dari keseluruhan pengalaman, mulai dari campaign, fotografi, komposisi katalog, product detail, sampai checkout.

Urutan pengerjaan yang saya sarankan adalah `design.md` → database & backend architecture → design system → homepage → catalog → product detail → cart & checkout → profile → community → admin CMS.

Dengan begitu, kita punya fondasi visual dan teknis yang konsisten sebelum mulai membangun seluruh fitur.
