# Creative Brief: "Dari ZIP ke Live"

## 1. Project Overview
- **Brand:** 1sLabs
- **Product:** 1sLabs Cloud Hosting Platform (Node.js & Laravel deployments, QRIS checkout, web control panel)
- **Target Audience:** Indonesian software developers, computer science students, indie hackers, and freelancers who have completed web apps and need a dependable, straightforward Indonesian hosting platform.
- **Duration:** 45 seconds (1334 frames @ 30 FPS).
- **Format:** 16:9 Landscape (1920x1080), with assets structured for subsequent 9:16 vertical reframe.

## 2. Core Creative Hook & Message
- **Primary Proposition:** Deploy aplikasi Node.js langsung dari browser, bayar lewat QRIS, tanpa kerumitan konfigurasi server manual.
- **Tone:** Practitioner-to-practitioner, calm, technical, authoritative, restrained. No marketing hype, no corporate buzzwords ("revolusioner", "terdepan", "all-in-one").
- **Aesthetic:** "Ink on paper" (monochrome `#111111` on `#EAEAEA` / white cards, with `#007AFF` interactive blue accent, subtle paper grain, and Bodoni Moda didone serif typography echoing the 1sLabs wordmark).

## 3. Narrative Arc (8 Scenes)
1. **The Hook (0:00 - 0:03.5):** Macro focus on Node.js row. Status badge flips to active running state. Bodoni reveal: "Kodenya sudah jadi."
2. **The Dilemma (0:03.5 - 0:09):** `npm run dev` running on localhost, cursor exits to empty browser. "Di laptop, semuanya jalan. Di internet, belum."
3. **The Solution (0:09 - 0:12.3):** Paper wipe to 1sLabs wordmark lockup. "Hosting dari 1sLabs."
4. **Order & Payment (0:12.3 - 0:19.1):** Hosting plan card deal-in, QRIS payment, proof upload, and human team verification ("menunggu verifikasi" -> approved).
5. **App Creation & Runtime (0:19.1 - 0:27.8):** Portal app wizard, choosing Node.js version, setting entry point, instant start, and streaming console logs.
6. **Deployment & File Editing (0:27.8 - 0:32.7):** ZIP upload drag-and-drop, automated extraction, and in-browser code editor.
7. **Complete Suite Tabs (0:32.7 - 0:39.5):** Sequential activation across the five core tabs: Overview, Files, FTP, Database, and Analytics.
8. **Call to Action (0:39.5 - 0:44.5):** Final wordmark lockup, clear URL `1slabs.my.id/hosting`, and consultation reassurance.
